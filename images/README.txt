画像の置き場所です（このフォルダごとGitHubにアップロードします）。
画像は「カード」と「詳細ポップアップ（紹介文の下）」の両方に使われます。
 
  images/hero.jpg                     トップの背景画像
 
  images/food/     食バザー     2-2, 2-4, 2-5, 2-6, 2-8, 2-S
  images/exhibit/  展示         1-1, 1-2, 1-4, 1-6, 1-7, 1-A, 2-1, 2-A
  images/stage/    ステージ/有志 1-3, 1-5, 1-8, 1-S, 2-3, 2-7,
                                grows, kinmokusei, sonmins, 2430, girls,
                                kani-club, longhair, inuyasai, nico-love, piano
  images/club/     部活動       chemistry, physics, biology, earth-science, photo,
                                art-general, art-course, tea, english, calligraphy,
                                cooking, broadcast, katei, library, shodo-sentaku,
                                art-sentaku, ikuryu, rindo, student-council
  images/map/      校内マップ   1f, 2f, 3f, 4f
 
例）images/food/2-2.jpg ／ images/club/chemistry.png
 
・ファイル名は半角英数字、大文字小文字も正確に（例：2-S は大文字のS）
・拡張子は小文字の .jpg .jpeg .png .webp
・団体を増やすときは、HTML内の CATEGORIES の file と同じ名前にします
